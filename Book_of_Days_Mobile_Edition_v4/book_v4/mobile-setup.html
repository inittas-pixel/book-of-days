Book of Days v4 Setup

Required

Publish the entire unzipped folder from one secure HTTPS web address. Offline caching cannot be installed from a local file address.

iPhone or iPad

  1. Open the HTTPS app address in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open the new icon once while online.
  4. Test with Airplane Mode.

Android

  1. Open the HTTPS app address in Chrome or Edge.
  2. Open the browser menu and select Install app or Add to Home screen.
  3. Open it once online, then test with Airplane Mode.

Data

Entries are private to each browser and device. Use Download backup, then Restore backup to move journal data between devices.

OneDrive and OneNote cloud setup

  1. Register a single-page app in Microsoft Entra ID for personal Microsoft accounts.
  2. Add delegated Microsoft Graph permissions Files.ReadWrite.AppFolder and Notes.Create.
  3. Acquire an access token for those scopes, paste it into the Backup screen, and keep the app open only on trusted devices.
  4. Use Back up to OneDrive, or enable automatic backup after changes.
  5. Use Export day to OneNote to create the current daily page in the named section.
